Install कैसे करें / How to install

  1. Chrome में यह page खोलें (WhatsApp के अंदर नहीं)।
  2. Download app दबाएँ। "File might be harmful" आए तो Download anyway.
  3. Download पूरा होने पर notification से या Files → Downloads से file खोलें।
  4. "Install unknown apps" पूछे → Settings → Chrome के लिए Allow → वापस आएँ।
  5. Install दबाएँ। "Play Protect" warning आए तो More details → Install anyway.

Update: नया version इसी तरह install करें — पुराना app हटाने की ज़रूरत नहीं, आपका data बना रहेगा।
